# Upwork Portfolio Packaging — V2

## 1. Cedarline Fencing — Local Service Lead-Generation Website

**Project Type**  
Independent spec project / product concept.

**Challenge**  
Local-service websites often lose leads because individual service pages drift apart visually, mobile CTAs are weak, quote forms are too long, and Google Ads traffic lands on pages without a clear next action.

**Approach / Solution**  
Designed a reusable service-page system with consistent hierarchy, persistent mobile call/quote actions, service-specific content blocks, and a short multi-step quote flow. The concept is intentionally structured so the same design logic could be implemented in WordPress/Elementor or another CMS.

**Tech Stack**  
Next.js, React, TypeScript, Tailwind CSS.

**Key Features**
- Conversion-focused hero and CTA structure
- Wood / vinyl / chain-link / ornamental service system
- Mobile sticky call + quote bar
- Two-step quote flow with validation and success state
- Reusable page sections for paid-traffic landing pages
- Responsive layout and performance-minded structure

**Live Demo**  
`/demo/local-service-lead-gen`

**Best Upwork Fit**  
WordPress landing pages, Elementor redesigns, local-service websites, Google Ads landing pages, responsive fixes, contact/quote-form improvements.

## 2. Aero One — DTC Product Landing Page

**Project Type**  
Independent spec project / product concept.

**Challenge**  
Generic ecommerce templates often present product information without building a persuasive buying path. Important benefits, objections, trust, variants, comparison, and purchase actions can feel disconnected.

**Approach / Solution**  
Rebuilt the page around the sequence of questions a buyer naturally asks: what the product solves, why it is different, what proof exists, how it compares, which variant to choose, what objections remain, and how to purchase.

**Tech Stack**  
Next.js, React, TypeScript, Tailwind CSS.

**Key Features**
- Premium product presentation
- Color variants and quantity controls
- Interactive cart drawer
- Sticky mobile purchase CTA
- Product story / specifications
- Comparison table
- Illustrative review section
- FAQ accordion
- Simulated checkout feedback

**Live Demo**  
`/demo/dtc-product-page`

**Best Upwork Fit**  
Shopify product-page redesign, ecommerce landing pages, conversion-focused product storytelling, responsive storefront UI, cart and variant interaction work.

## 3. Relay Operations — B2B SaaS Dashboard

**Project Type**  
Independent spec project / product concept.

**Challenge**  
Data-heavy SaaS dashboards become difficult to use when KPIs, charts, filters, records, workflow actions, and operational alerts all compete for attention.

**Approach / Solution**  
Created a clear information hierarchy that starts with the executive pulse, surfaces risk separately, and keeps search, filtering, sorting, detail inspection, record creation, and export close to the data they affect.

**Tech Stack**  
React, Next.js, TypeScript, Tailwind CSS, Recharts.

**Key Features**
- KPI system and interactive area chart
- Attention / risk queue
- Search and status filtering
- Value sorting and pagination
- Workflow detail drawer
- New-workflow modal
- CSV export feedback
- Responsive mobile navigation

**Live Demo**  
`/demo/saas-operations-dashboard`

**Best Upwork Fit**  
React / Next.js dashboards, admin panels, customer portals, SaaS UI modernization, Figma-to-frontend, data-table and chart work.
