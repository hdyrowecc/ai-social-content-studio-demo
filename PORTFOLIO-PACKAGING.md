# Upwork / Portfolio Packaging

## 1. AI Social Content Studio
**Challenge**  
Marketing teams often lose time rewriting one campaign idea for multiple social channels and maintaining consistency across drafts.

**Approach / Solution**  
Designed a focused SaaS workflow that turns a short campaign brief into multiple channel-aware drafts. The prototype includes realistic loading, generation, history, pricing, login, export, and feedback states while intentionally simulating the external AI service.

**Tech Stack**  
Next.js, React, TypeScript, Tailwind CSS, Lucide.

**Key Features + Live Demo**  
Interactive brief builder, platform/tone controls, simulated AI generation, copy/export behavior, campaign history, pricing states, responsive mobile UI.  
Live Demo: `/demo/ai-social-content-studio`

## 2. Atelier Commerce
**Challenge**  
Premium independent brands need ecommerce experiences that feel editorial without sacrificing simple, obvious buying interactions.

**Approach / Solution**  
Created a high-end storefront combining restrained typography, product storytelling, theme switching, responsive navigation, variants, quantity controls, and a cart drawer with a simulated checkout flow.

**Tech Stack**  
Next.js, React, TypeScript, Tailwind CSS, Lucide.

**Key Features + Live Demo**  
Light/dark mode, premium product presentation, smooth collection navigation, size variants, cart drawer, quantity updates, responsive mobile menu, simulated checkout.  
Live Demo: `/demo/premium-ecommerce`

---

## 3. Command Center
**Challenge**  
Operations teams need dense business data to remain easy to scan, filter, compare, and act on.

**Approach / Solution**  
Built a responsive analytics dashboard with KPI hierarchy, revenue visualization, acquisition breakdowns, searchable records, status filters, sorting, pagination, record creation, and simulated CSV export.

**Tech Stack**  
Next.js, React, TypeScript, Tailwind CSS, Recharts, Lucide.

**Key Features + Live Demo**  
KPI cards, interactive chart, filters, sorting, pagination, create-record modal, responsive data table, export feedback.  
Live Demo: `/demo/admin-dashboard`
