# Roecc — Web Product Portfolio V2

A single Next.js portfolio site built around real freelance hiring use cases rather than generic frontend demos.

## Live structure
- `/` — Portfolio home
- `/demo/local-service-lead-gen` — Local service / lead-generation website
- `/demo/dtc-product-page` — DTC ecommerce product landing page
- `/demo/saas-operations-dashboard` — B2B SaaS operations dashboard

Legacy demo URLs redirect to the new V2 projects.

## Positioning
All three projects are independent **spec projects / product concepts**. They are built to demonstrate commercial UX thinking, responsive frontend execution, interaction states, and practical problem-solving.

No fake client names, real revenue claims, user counts, testimonials, or production claims are used.

## Why these three projects
They map directly to common freelance requests:
- WordPress / Elementor / local-service landing pages and quote flows
- Shopify / ecommerce product-page redesign and conversion work
- React / Next.js SaaS dashboards and frontend modernization

## Stack
- Next.js App Router
- React + TypeScript
- Tailwind CSS
- Lucide
- Recharts

## Local development
```bash
npm install
npm run dev
```
